راهنمای پروژهٔ ArvanCloud Let's Encrypt

ساخت کلید دسترسی آروان‌کلاد و رفع خطای دسترسی به دامنه

اگر هنگام صدور گواهی پیام زیر را می‌بینید، معمولاً کلید به رابط API می‌رسد اما مجوز مشاهدهٔ زون موردنظر را ندارد:

The ArvanCloud key can reach the API but cannot see the requested DNS zone.
نکته: صرفاً ساختن کلید کافی نیست. باید برای ماشین‌کاربر یک قانون دسترسی تعریف کنید که زون example.com و عملیات لازم روی رکوردهای DNS را پوشش دهد.

پیوندهای رسمی و مستقیم

ورود به صفحهٔ ماشین‌کاربرها در پنل آروان‌کلاد panel.arvancloud.ir/profile/iam/machine-users مستندات رسمی ساخت و دریافت کلید دسترسی docs.arvancloud.ir/fa/developer-tools/api/api-key/ مستندات رسمی قوانین دسترسی docs.arvancloud.ir/fa/accounts/iam/policies/

مراحل ساخت کلید

  1. وارد پنل آروان‌کلاد شوید و صفحهٔ IAM → Machine Users را باز کنید. اگر پیوند مستقیم به صفحه منتقل نشد، از منوی تنظیمات وارد بخش IAM و سپس فهرست ماشین‌کاربرها شوید.
  2. گزینهٔ ساخت ماشین‌کاربر جدید را انتخاب کنید و برای آن نامی بگذارید. طبق مستندات آروان، نام باید از حروف کوچک انگلیسی، عدد و خط تیره تشکیل شود و بین ۵ تا ۱۰۰ نویسه باشد.
  3. کلید دسترسی تولیدشده را همان لحظه کپی کرده و در محل امن نگه دارید. طبق مستندات آروان، پس از بستن صفحه امکان بازیابی دوبارهٔ مقدار کلید وجود ندارد.

دادن مجوز درست برای DNS

  1. از بخش تنظیمات → IAM → قوانین دسترسی وارد مدیریت مجوزها شوید. در صورت نیاز از صفحهٔ مدیریت منابع نیز می‌توانید قانون را روی میزکار یا منبع مربوط تعریف کنید.
  2. ماشین‌کاربری را که ساخته‌اید به قانون دسترسی اضافه کنید.
  3. منبع یا میزکاری را انتخاب کنید که زون example.com در آن قرار دارد و نقشی بدهید که اجازهٔ مشاهدهٔ زون و خواندن، ساختن و حذف رکوردهای DNS را داشته باشد. این ابزار برای اعتبارسنجی DNS-01 باید رکورد موقت TXT با نام _acme-challenge را مدیریت کند.
  4. قانون را ذخیره کنید و مطمئن شوید به همان ماشین‌کاربر و همان منبع اعمال شده است. دسترسی را تا جای ممکن به همان منبع محدود نگه دارید؛ بدون نیاز دسترسی مدیر کل ندهید.

اگر هنوز خطا دریافت می‌کنید

  • بررسی کنید example.com در سرویس DNS آروان و در همان حساب یا میزکاری وجود داشته باشد که کلید از آن ساخته شده است.
  • بررسی کنید دامنه را فقط به‌عنوان دامنهٔ ثبت‌شده ندارید؛ باید زون DNS آن در پنل آروان قابل مشاهده باشد.
  • قانون دسترسی را پس از افزودن ماشین‌کاربر ذخیره و اعمال کنید. صرفِ ایجاد کلید به آن دسترسی خودکار به دامنه نمی‌دهد.
  • دوباره نصب‌کننده را اجرا کنید و کلید کامل را در ورودی مخفی وارد کنید. می‌توانید مقدار خام کلید یا مقدار دارای پیشوند Apikey را وارد کنید. کلید را در چت، اسکرین‌شات یا گزارش عمومی منتشر نکنید.

پس از تغییر مجوزها، منوی نصب‌کننده را دوباره باز کرده و گزینهٔ صدور گواهی را اجرا کنید.

نصب‌کننده

دستور زیر نصب‌کنندهٔ نسخهٔ v1.1.0 را اجرا می‌کند. پیش از اجرا، محتوای اسکریپت‌های راه‌دور را بررسی کنید:

curl -fsSL https://raw.githubusercontent.com/power0matin/arvancloud-letsencrypt/v1.1.0/install.sh | sudo bash

مستندات رسمی آروان‌کلاد مبنای مسیر ساخت کلید و تنظیم قوانین دسترسی این راهنما هستند. نام گزینه‌های پنل ممکن است با تغییر رابط کاربری کمی متفاوت شود.
